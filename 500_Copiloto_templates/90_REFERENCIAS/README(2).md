# EXECUTAR — Mapa das áreas

Infográfico A4 retrato, modo HIERARCHY_MAP. Fonte: IMG_4287.jpeg.

## Conteúdo
- SVG: matriz vetorial editável.
- PNG: 2480 × 3508 px para visualização/impressão A4 a aproximadamente 300 dpi.
- MASTER_INDEX.csv e entities.json: 17 pastas observadas, com nomes originais e nomes normalizados.
- relations.csv: apenas cabeçalho, pois nenhuma relação entre pastas foi comprovada.
- audit.json e evidence.json: auditoria e evidências.

## Critérios
D01–D16 preservados. SRC-FOLDER-001 é um ID gerado para a pasta adicional. O cabeçalho On My iPad contextualiza a tela; não estabelece caminho físico. As áreas têm o estado existing porque aparecem na foto. Isso não comprova prontidão, implementação ou conteúdo. Não foram gerados subIDs para os 7 itens que a interface indica em cada área. Versões, responsáveis e caminhos permanecem nulos. CTA sem URL é somente visual. Nenhum arquivo ou pasta da estrutura fotografada foi criado ou reorganizado.

## Progressive disclosure
P0: infográfico com áreas e identificação. P1: índice e JSON. P2: auditoria, limitações e evidências.

## Pipeline
INSPECT → INVENTORY → NORMALIZE → CLASSIFY → IDENTIFY → RELATE → AUDIT → SELECT_VIEW → DISCLOSE → COMPOSE → RENDER → INSPECT_RENDER → VERIFY → EVIDENCE → DELIVER.
