# 500_Copiloto_templates

Templates, schemas, regras e script reutilizáveis para organizar o workbook.

| Pasta | Conteúdo |
|---|---|
| `templates/` | capa, capítulo, seção, tarefa, checklist de fechamento |
| `schemas/` | JSON Schema de IDs, front matter de seção, tarefa e status de área |
| `regras/` | `OPERACOES.md` (tripla clonagem) e `ACOMPANHAMENTO.md` (completude) |
| `scripts/workbook.py` | `status`, `index`, `check`, `build` |

Placeholders dos templates usam `{CHAVE}`. Edite aqui, não nas cópias.
